Deskripsi Proyek 
> Aplikasi ini merupakan sistem pencatatan tugas mata kuliah yang berfungsi untuk membantu mahasiswa mengatur dan memantau tugas-tugas kuliah.
> Sistem ini memiliki fitur CRUD (Create, Read, Update, Delete) serta pencarian tugas (search).
Dengan aplikasi ini, pengguna dapat menambahkan tugas baru, melihat daftar tugas, mengedit tugas yang sudah ada, dan menghapus tugas yang sudah selesai.

Alasan Memilih Tema
